Serve React Frontend from FastAPI at /dashboard                                                                                                                                                                         │
│                                                                                                                                                                                                                         │
│ Context                                                                                                                                                                                                                 │
│                                                                                                                                                                                                                         │
│ The frontend (React + Vite) and backend (FastAPI) are completely disconnected. The goal is to have FastAPI serve the built React app at GET /dashboard, so the entire app runs from a single server at                  │
│ http://127.0.0.1:8000.                                                                                                                                                                                                  │
│                                                                                                                                                                                                                         │
│ Key codebase state that affects this plan:                                                                                                                                                                              │
│ - React Router is set up with client-side routes (/login, /register, /). FastAPI must serve index.html for all /dashboard/* paths (SPA catch-all) so React Router handles navigation.                                   │
│ - BrowserRouter in main.jsx currently has no basename — needs basename="/dashboard".                                                                                                                                    │
│ - Backend CWD is backend/ — python main.py runs from backend/, so paths to frontend/dist/ must use __file__-relative resolution (not CWD).                                                                              │
│ - Backend has been restructured — database endpoints now use modular routers (routers/users.py, etc.) with app.include_router(), Pydantic schemas (schemas/), dependency injection (dependencies.py), and a             │
│ standardized response envelope (schemas/response.py).                                                                                                                                                                   │
│ - The static mount must go after app.include_router() calls and the validation error handler.                                                                                                                           │
│                                                                                                                                                                                                                         │
